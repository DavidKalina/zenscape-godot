# ZenScape native parity

Acceptance target (updated by the user): closely resemble the original ZenScape
and deliver a beautiful, responsive Godot landscape with working environmental
systems. Literal 1:1 visual or equation parity is no longer required; the Godot
version is expected to diverge. Prioritize noticeable improvements to shaders,
lighting, atmosphere, motion and interactions. Frame-rate optimization remains
paused. Journaling is not required.

The source comparisons below are useful references and existing verification,
not a requirement to reproduce every implementation detail. Judge changes at
normal viewing distances and in motion; use focused tests for meaningful bugs
and regressions. General procedural generation and new biome coverage are future
sandbox expansion, not prerequisites for improving this current imported scene.
The source checkout remains unchanged.
